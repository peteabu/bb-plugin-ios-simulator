## Replay and shared control

- Capture up to the last 30 seconds of iOS video, play or scrub a saved
  capture, jump to activity events, and download replay JSON.
- Use Take control and Let agent drive to hand one device between a human
  and an agent. Handoff cancels the previous driver's pending input.
- Choose devices with the updated picker and use the compact control dock,
  Device options and Activity drawer.

## Responsiveness fixes

- Live viewing and replay recording share one native H.264 encoder.
- A new control lease reconnects input immediately instead of waiting for
  the connection-failure retry.
- Activity rows avoid unnecessary playback renders, and app-log retention
  caches event byte sizes. An isolated 100-event browser fixture showed about
  80% less React rendering work; this is not a live-device FPS measurement.

## Validation and requirements

The implementation passed 199 plugin tests, 26 native support tests,
TypeScript, plugin/native builds and a two-decoder native integration check.
Native BB-window replay/handoff rechecking remains unverified because desktop
automation permission was unavailable; the controlled browser and native
checks are documented in the repository.

iOS requires BB 0.46+, an Apple Silicon Mac with Xcode's iOS platform and
Node.js 20+. Replay buffers are temporary and bounded, and playback requires
WebCodecs. Android remains an emulator screenshot preview using an existing
SDK and AVD.
